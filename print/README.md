# Models to print

Every file here is published on [qutie.org](https://qutie.org) with an
interactive 3D preview and download buttons. The filename becomes the display
name: `Qutie System Two.stl` shows up as **“Qutie System Two”**.

- `<model>.stl`: one piece, for a single-colour print.
- `<model>.3mf`: the same model as one object with a part per colour, each
  named after its filament (e.g. “wall - matte black”) and set to its own
  extruder. PrusaSlicer, Bambu Studio and OrcaSlicer load it ready for a
  multi-colour print; you only check which filament each extruder holds.
- `parts/`: the bodies as separate STLs, for slicers that do not read 3MF.

Generated by the scripts in [`../cad`](../cad); the originals they were
rebuilt from are in [`../originals`](../originals).
